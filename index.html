Comparador digital de 3 bits

Activa o desactiva los bits de los puertos A y B. Observa las salidas A > B, A = B y A < B, y revisa cómo se obtiene cada resultado.

1. Entradas binarias

Presiona un bit para cambiarlo entre 0 y 1. El bit 2 es el más significativo (MSB).

Puerto A
101
Decimal: 5
Puerto B
011
Decimal: 3
Rango de cada puerto: 000 a 111 (0 a 7 en decimal).

2. Salidas del comparador

Una sola salida es 1 para cada combinación de entradas.

A > B
1
A = B
0
A < B
0
Resultado: 5 > 3

3. ¿Cómo se determina el resultado?

Se comparan los bits desde el más significativo. El primer par diferente determina cuál número es mayor.

4. Ecuaciones booleanas

Las siguientes expresiones permiten implementar el comparador utilizando únicamente compuertas lógicas.

E₂ = A₂ XNOR B₂
E₁ = A₁ XNOR B₁
E₀ = A₀ XNOR B₀
A = B = E₂ · E₁ · E₀
A > B = (A₂ · ¬B₂) + (E₂ · A₁ · ¬B₁) + (E₂ · E₁ · A₀ · ¬B₀)
A < B = (¬A₂ · B₂) + (E₂ · ¬A₁ · B₁) + (E₂ · E₁ · ¬A₀ · B₀)
Donde · significa AND, + significa OR y ¬ significa NOT. XNOR vale 1 cuando los bits comparados son iguales. Las ecuaciones son una implementación combinacional; no se dibujan aquí las compuertas individuales.

5. Tabla de verdad completa

El comparador tiene 6 entradas en total (3 por puerto), por lo que existen 2⁶ = 64 combinaciones. Toca cualquier fila para cargarla en el simulador.
